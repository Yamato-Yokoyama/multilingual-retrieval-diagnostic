# Data

Course-restricted datasets used in this project are not included in this repository.

## Expected files
- `nlp2-a3.train` — Week 2 training data (20000 words)
- `nlp2-a3.test` — Week 2 test data (5000 words)
- `p2-train.txt` — Week 1 training data
- `p2-test.txt` — Week 1 test data

## Format
- Week 1: `word\t{0,1}` — word and compound label
- Week 2: space-separated segments, one word per line (e.g., `schmelz wasser rinne`)
